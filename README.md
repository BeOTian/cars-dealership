# Cars Dealership Capstone Project

## Project Overview
This is a full-stack web application for a national car retailer in the U.S. called Cars Dealership. It allows users to view dealership branches across the country, view customer reviews, and submit new reviews.

## Technologies Used
*   **Frontend:** React.js, HTML, CSS
*   **Backend:** Django, Python, Node.js
*   **Database:** SQLite, MongoDB
*   **Deployment:** Docker, Kubernetes, IBM Cloud Code Engine
